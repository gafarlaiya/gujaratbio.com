# www.gujaratbio.com

Main website of Gujarat Bio Organics Private Limited: farmers, crops, Immunity products, knowledge, company.
Plain HTML generated by `build.py` from the `content_*.py` / `content_articles.json` files. Served by `server.js` (Node, no dependencies) on Hostinger.

- Edit content, then run `python3 build.py` and commit everything.
- `redirects.json`: 301 redirects for old www URLs. `host.json`: gujaratbio.com and agriculture.gujaratbio.com redirect to www.
- Photos/videos: save files named as in `MEDIA_LIST.csv` into `assets/media/` and rebuild.
- Business site (bulk, OEM, export) is a separate repo: gafarlaiya/b2b.gujaratbio.com.
